# Site Systems Diagnostic — capability test

A synthetic end-to-end test of the engagement ETABLIX advertises: the client
supplies eight inputs, ETABLIX returns twelve deliverables within ten working
days.

**Nothing here is a real project, client or contract.** "Ridgeway Grid
Connection" is invented for this test. No figure, name or date in `inputs/`
describes anything that exists. It is written to be *realistic enough to be
hard* — the numbers are internally consistent, some information is missing,
and two of the inputs quietly contradict each other, because that is what a
real handover looks like.

- `inputs/` — the eight things the website asks a client to provide
- `output/` — what ETABLIX produced from them
- `output/CAPABILITY-VERDICT.md` — the honest assessment: which of the twelve
  deliverables the platform's own agents produce today, which need a human,
  and which had no producer at all before this test
